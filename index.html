Apprenez les bases avec un terminal interactif

Dictionnaire des Commandes

  • pwd : Affiche le chemin du dossier actuel (Print Working Directory).
  • ls : Liste les fichiers et dossiers présents.
  • cd [dossier] : Permet de se déplacer dans un autre répertoire (Change Directory).
  • echo [texte] : Affiche le texte saisi à l'écran.
  • clear : Nettoie l'affichage du terminal.
